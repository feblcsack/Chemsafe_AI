Place custom Hazmon artwork here.

## Required Files (9 total):

1. `ignivore.png` - Flammable Hazmon (Fire theme)
2. `oxidrax.png` - Oxidizing Hazmon (Plasma/Electric theme)
3. `detonyx.png` - Explosive Hazmon (Bomb/Blast theme)
4. `corrolith.png` - Corrosive Hazmon (Acid/Slime theme)
5. `venomask.png` - Acute Toxic Hazmon (Poison/Skull theme)
6. `pulmonar.png` - Health Hazard Hazmon (Lung/Bio theme)

8. `aquabane.png` - Environment Hazmon (Polluted water theme)
9. `pressuron.png` - Compressed Gas Hazmon (Wind/Pressure theme)

## Specifications:

- **Size:** 512x512 px (square)
- **Format:** PNG (transparent background recommended) or JPG
- **File Size:** Max 500KB each
- **Naming:** Lowercase, no spaces, .png extension

## Fallback Behavior:

If artwork file is missing or fails to load, the card will automatically show:
- Lucide icon (current default)
- Color background from Hazmon theme
