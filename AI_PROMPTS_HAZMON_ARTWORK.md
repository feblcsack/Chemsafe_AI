## 📝 Tips untuk AI Generation

### ChatGPT (DALL-E 3):
1. Copy prompt di atas
2. Paste ke ChatGPT
3. Generate image
4. Download hasil (512x512 auto)
5. Optimize dengan TinyPNG jika >500KB

### Midjourney:
Tambahkan parameters:
```
[prompt above] --ar 1:1 --v 6 --style raw --q 2
```

### Leonardo.ai:
- Model: Leonardo Diffusion XL
- Dimensions: 512x512
- Guidance Scale: 7
- Style: Anime/Illustration

## 🎨 Variations

Jika hasil kurang sesuai, tambahkan:

**More cute:**
```
, cuter expression, rounder features, big eyes, friendly appearance
```

**More dangerous:**
```
, sharper features, intense expression, more threatening pose, darker colors
```

**More simple:**
```
, minimal details, flat colors, icon-style, vector art
```

**More detailed:**
```
, intricate details, textured surface, dynamic shading
```

## 🔄 Batch Generation (Save Time)

Generate semua 9 sekaligus dengan prompt:

```
Create 9 different Pokemon-style creature characters for a chemical safety app, 
each representing a different hazard type. Each character should be:
- 512x512 pixels
- Simple, bold design
- Clear silhouette
- Transparent background
- Unique theme based on chemical hazard

Characters:
1. Fire elemental (red/orange)
2. Electric plasma (yellow/white)
3. Explosive bomb (orange/black)
4. Acid slime (green)
5. Poison ghost (purple)
6. Bio-hazard (gray)
7. Irritant spiky (yellow)
8. Toxic water (teal)
9. Compressed gas (cyan)

Style: Pokemon/Digimon mascot characters, friendly but dangerous
Grid layout: 3x3, label each character
```

**Note:** Batch generation might need manual separation and resizing.
